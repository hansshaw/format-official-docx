# 公文 DOCX 格式规格

## 精确参数

| 项目 | 规格 | OOXML/实现值 |
| --- | --- | --- |
| 纸张 | A4 纵向，21.0 x 29.7 cm | 约 11906 x 16838 twips |
| 页边距 | 上 3.7、下 3.5、左 2.8、右 2.6 cm | 约 2098、1984、1587、1474 twips |
| 标题 | 方正小标宋简体，二号，居中 | 22 pt；w:sz=44 |
| 一级标题 | `一、`；黑体，三号 | 16 pt；w:sz=32 |
| 二级标题 | `（一）`；楷体_GB2312，三号 | 16 pt；w:sz=32 |
| 三级标题 | `1.`；仿宋_GB2312，三号 | 16 pt；w:sz=32 |
| 四级标题 | `（1）`；仿宋_GB2312，三号 | 16 pt；w:sz=32 |
| 正文 | 仿宋_GB2312，三号 | 16 pt；w:sz=32 |
| 正文首行 | 缩进 2 字符 | w:ind w:firstLineChars=200 |
| 行距 | 固定值 29 磅；段前、段后 0 | w:line=580；w:lineRule=exact |
| 页码 | 宋体，四号，居中，动态阿拉伯数字 | 14 pt；w:sz=28；- PAGE - |
| 页脚位置 | 距页面底端 2.8 cm | 与版心下边缘约留 0.7 cm |

将提示中的“仿宋-GB2312”写入 Word 时使用实际字体族名“仿宋_GB2312”，二级标题字体使用实际字体族名“楷体_GB2312”，主标题字体使用“方正小标宋简体”。不得只设置 eastAsia 字体；同时设置 ascii、hAnsi、eastAsia 和 cs，并移除主题字体属性，避免 Word 或 LibreOffice 静默改用主题字体。

页码中的 PAGE 必须是字段，不得写死数字。字段结构使用 begin、instrText、separate、缓存结果和 end，字段指令为 PAGE \* Arabic；首次生成时缓存结果为 1，之后 Word 更新为其他阿拉伯数字也仍然有效。begin 标记 dirty=true，并在 settings.xml 中设置 updateFields=true。

## 标题排列

先按语义断行，再检查形状。把一个全角汉字、全角标点按 1 个视觉单位计算，把半角拉丁字母、数字按 0.5 个视觉单位计算。

- 单行：不超过约 20 个全角视觉单位，避免 Word 再次自动换行。
- 梯形：各行总体单调变长或单调变短，例如 10、14 或 16、13、10。
- 菱形：先变长再变短，例如 10、16、12。
- 禁止矩形：各行几乎等长，例如 14、14。
- 禁止沙漏：先变短再变长，例如 16、10、16。

只在同一个居中标题段落中使用显式换行。不得添加空格、Tab 或其他空白字符造形，不得把每行拆为不同字号，也不得使用文本框控制位置。几何检查不能判断词义；逐页渲染时还要确认机构名、法规名、专有名词和修饰关系未被割裂。

## 正文标题层级

文档首个非空正文顶层段落作为主标题，排除在层级识别之外。其余正文顶层独占段落按开头编号识别；包在内容控件中的顶层段落仍属于识别范围，表格、文本框和页脚不属于识别范围。

- 一级标题：以 `一、` 开头，中文序号支持 `十一、` 等多位形式；黑体三号；句末不得有标点。
- 二级标题：以 `（一）` 开头，中文序号支持 `（十一）` 等多位形式；楷体_GB2312 三号；句末标点可有可无。
- 三级标题：以 `1.` 开头，支持 `12.` 等多位形式但不把 `1.5` 识别为标题；仿宋_GB2312 三号；句末必须有标点。
- 四级标题：以 `（1）` 开头，支持 `（12）` 等多位形式；仿宋_GB2312 三号；句末必须有标点。

一级、二级标题未单独指定字号，作为正文标题沿用三号（16 磅）。所有层级标题均改用 Normal 段落样式，取消直接及样式继承的首行和悬挂缩进，但保留已有左右缩进，并设置 `w:keepNext` 和 `w:keepLines`。标题运行不叠加 Word 粗体、斜体或下划线；一级标题的黑体字形本身不等于额外设置粗体。

编号前不得有字面空格、Tab 或换行，编号后必须包含至少一个非空白、非标点的实际标题字符。二级、四级必须使用全角括号，三级必须使用半角句点；`(一)`、`(1)` 和 `1．` 均视为错误编号。审计句末标点时允许标点后跟闭合引号或书名号，例如 `1.有关要求。` 与 `1.有关要求。”` 均合规。

层级标题使用字面编号，不得同时使用 Word 自动编号（`w:numPr`），否则可能渲染出双编号。格式化时清除段落直接自动编号并通过 Normal 样式阻断样式继承的编号；审计同时检查段落及其样式链中的自动编号和缩进。

## 适用边界

本规格实现用户明确给出的版面、标题、正文、行距和页码要求，并采用 A4 纵向及居中页码作为统一公文基线。它不声称覆盖 GB/T 9704 的全部要素，例如版记、发文机关标志、红色分隔线、签发人、单双页外侧页码或印章位置。用户补充这些要求时，以补充要求为准，并扩展审计。

正文自动范围包括 document.xml 内的段落运行、表格、超链接和文本框。页眉、脚注、尾注、批注、嵌入对象及其他独立 OOXML 部件需要单独处理。

正文首行缩进的范围比字体和行距范围窄：只处理普通正文顶层段落，包括包在内容控件中的正文段落；主标题、层级标题、表格单元格、文本框和页脚不应用正文首行缩进。写入 `w:firstLineChars="200"` 时删除同一 `w:ind` 上冲突的 `w:firstLine`、`w:hanging` 和 `w:hangingChars`，但保留左右缩进等无关属性。
